# static 界面同步记录

本轮以相邻的 `../NetherLink` 正式版源码为参照，只更新已有页面的界面和公共绘制组件。static 的本地数据仓库、模拟 AI 流式回复、登录注册、聊天、联系人和评论操作继续使用原实现。

## 液态玻璃

原先两个片段着色器已被移植，但 `QtFallbackLiquidGlass` 仍使用旧接口。界面同步时保留已有着色器内容，同步正式版的渲染器与控制器，以下五个文件建立了与正式版相同的基线；后续磨砂玻璃材质调整见下一节：

- `resources/shaders/qt_fallback_liquid_glass.vert`
- `resources/shaders/qt_fallback_liquid_glass.frag`
- `resources/shaders/qt_fallback_liquid_glass_blur.frag`
- `shared/ui/QtFallbackLiquidGlass.h`
- `shared/ui/QtFallbackLiquidGlass.cpp`

同步内容包括原图/柔化图双纹理、`u_pixelScale` 和 `u_texelSize` 参数、六轮横纵模糊、线性纹理过滤、固定渲染分辨率、外围 32 DIP 背景采样与裁切，以及染色、描边和内高光。

各入口遵循正式版已有设置：

| 入口 | 绘制路径 |
| --- | --- |
| 聊天输入栏：Qt 液态玻璃 | 新 GLSL 着色器和公共渲染器 |
| 聊天输入栏：Qt 高斯模糊 | 公共控制器的高斯模糊路径 |
| 聊天输入栏：macOS 原生液态玻璃/毛玻璃 | macOS 原生桥接，不使用 GLSL 着色器 |
| 帖子导航栏及加号：Qt 模糊 | 与正式版相同，使用高斯模糊 |

另同步了输入栏从 macOS 原生模式切换到 Qt 模式时显式显示输入框和工具按钮的修复。static 原有模拟对方发送、撤回等快捷操作保留。

## 磨砂玻璃材质调整

材质先在 static 调整，用户确认后已同步至正式版 NetherLink 的着色器、渲染器及输入栏阴影。效果继续使用现有 GPU 模糊与片段着色器：

- 六轮横纵 GPU 模糊保持不变，采样步长改为 1.15 DIP 并乘显示缩放，使磨砂强度不随 Retina 分辨率减弱。
- 以柔化图为主要透射层，配合轻微降饱和、固定细颗粒和少量烟灰吸收色。
- 去掉偏向上侧、左侧的方向高光及内沿亮边，改为四边一致的微弱环境反光与曲率明暗。
- 吸收色强度降为浅色 0.025、深色 0.045，并适当提升透射亮度，减轻整体压暗。
- Qt 液态玻璃聊天输入栏增加柔和外投影（Qt 阴影效果，模糊半径 16、向下偏移 2），玻璃材质继续使用 GPU；投影不额外压暗玻璃内部。
- 降低折射与色散强度；GPU 结果不再叠加原有平面染色、整面渐变高光或 QPainter 内外描边，QPainter 仅负责裁切和贴图。
- 高斯模糊模式与 macOS 原生模式保持原实现。无新增纹理、uniform 或模糊轮次。

主要调节位置：`shared/ui/QtFallbackLiquidGlass.cpp` 中的 `kLiquidGlassFrostBlurStepDip`；片段着色器中的 `kFrostAmount`、`kFrostGrain`、`kRefraction`，以及吸收色与边缘光照参数。按要求只编译，不启动。

## 验证

- 使用现有 Qt 6.11 macOS Debug 配置编译：`cmake --build build/Qt_6_11_0_for_macOS-Debug -j 6`。
- 界面同步阶段对上述五个液态玻璃文件做逐字节比较，并检查资源注册与调用入口；后续确认的材质改动已同步正式版，玻璃着色器及渲染器再次逐字节一致，输入栏阴影方法保持一致。
- 检查没有引入 Qt Network 依赖或正式版网络数据源。
- 按用户要求不启动应用；视觉效果及交互由用户运行验收。检查自定义着色器效果时，请在外观设置的“聊天输入栏”中选择 Qt 液态玻璃。
